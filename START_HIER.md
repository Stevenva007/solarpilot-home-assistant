# SolarPilot starten of bijwerken

Installeer **1.0.0-beta.108** via HACS, herstart Home Assistant volledig en herlaad de app of browser.

Open **Voorrang** om de centrale volgorde te controleren. De Wallbox staat standaard als laatste. Een eigen eerder opgeslagen volgorde blijft behouden.

Een handmatig ingeschakeld SG-contact behoudt de afteller van vijftien minuten. De gewone wolkenbuffer blijft standaard vijf minuten; de afzonderlijke netgrens kan SG direct vrijgeven terwijl de autonoom regelende Wallbox nog laadt. Een langere buffer verandert die grens niet.
